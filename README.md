PrettyKnots:-

About the Project:
PrettyKnots is a website project designed to provide users with an easy and user-friendly browsing experience. It includes different pages to explore products, learn about the website, contact us, and place orders.

Pages Included:
- Home Page: Introduction to PrettyKnots.
- About Page: Information about the website.
- Product Page: Displays available products.
- Order Page: Provides an order page.
- Contact Page: Allows users to contact us.

Technologies Used:
- HTML5
- CSS3

Project Structure:
- `index.html` – Home Page
- `about.html` – About Page
- `product.html` – Product Page
- `order.html` – Order Page
- `contact.html` – Contact Page
- `images/` – Website images
- `README.md` – Project documentation
  
Project Purpose:
The purpose of this project is to practice web development skills and create a structured and user-friendly website using HTML and CSS.
